# 設計系統模板 (Design System Template)

這是一個完整的設計系統模板專案，包含可重用的組件、樣式系統和設定檔，方便您在新專案中快速使用。

## 📦 包含內容

### 組件 (Components)

- **Footer** - 置底資訊組件，可配置作者、連結、年份
- **FloatingMascot** - 浮動角色組件，支援自訂圖片、連結、位置和大小
- **PageLayout** - 標準頁面佈局組件，整合 Footer 和 FloatingMascot

### 樣式系統 (Styles)

- 完整的 CSS 變數系統（顏色、間距、陰影）
- 漸層效果定義
- 動畫效果（float, wave, marquee, pulse-glow）
- 工具類別（glass-card, gradient-text, upload-zone）

### 設定檔

- Tailwind CSS 設定
- TypeScript 設定
- Vite 設定
- PostCSS 設定

## ✅ 新專案必備元素檢查清單

開始使用此模板建立新專案時，請確保完成以下必要元素的設定：

### 📸 圖片資源 (放在 `public/` 目錄)

#### Favicon 圖示（必須）
- ✅ `favicon.ico` - 傳統 favicon（16x16 或 32x32，建議 32x32）
- ✅ `favicon-16x16.png` - 16x16 PNG 格式
- ✅ `favicon-32x32.png` - 32x32 PNG 格式

#### PWA 圖示（建議）
- ✅ `icon-apple-180x180.png` - Apple Touch Icon（180x180）
- ✅ `icon-android-192x192.png` - Android 圖示（192x192）
- ✅ `icon-pwa-512x512.png` - PWA 圖示（512x512）

#### 社交媒體分享圖（必須）
- ⚠️ `og-image.png` - Open Graph 分享圖（**1200x630 像素**）
  - 用於 Facebook、Twitter、LinkedIn 等社交平台分享預覽
  - 建議使用 PNG 或 JPG 格式
  - 檔案大小建議 < 1MB

#### Twitter Card 圖（建議）
- ⚠️ `twitter-card.png` - Twitter 專用分享圖（**1200x600 像素**）
  - 如果與 OG Image 相同，可共用同一張圖

### 🔧 HTML Meta Tags 設定（編輯 `public/index.html`）

在 `<head>` 區塊中，請更新以下內容：

```html
<!-- 基本資訊 -->

<meta name="description" content="網站描述（建議 150-160 字元）" />
<meta name="keywords" content="關鍵字1, 關鍵字2, 關鍵字3" />
<meta name="author" content="作者名稱" />

<!-- 主題色彩 -->
<meta name="theme-color" content="#3b82f6" />

<!-- Open Graph (Facebook, LinkedIn 等) -->
<meta property="og:type" content="website" />
<meta property="og:url" content="https://your-website.com" />
<meta property="og:title" content="你的網站名稱" />
<meta property="og:description" content="網站描述" />
<meta property="og:image" content="https://your-website.com/og-image.png" />
<meta property="og:image:width" content="1200" />
<meta property="og:image:height" content="630" />
<meta property="og:site_name" content="你的網站名稱" />
<meta property="og:locale" content="zh_TW" />

<!-- Twitter Card -->
<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:url" content="https://your-website.com" />
<meta name="twitter:title" content="你的網站名稱" />
<meta name="twitter:description" content="網站描述" />
<meta name="twitter:image" content="https://your-website.com/twitter-card.png" />

<!-- 網站圖示（已包含，確認路徑正確） -->
<link rel="icon" type="image/x-icon" href="/favicon.ico" />
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png" />
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png" />
<link rel="apple-touch-icon" sizes="180x180" href="/icon-apple-180x180.png" />
<link rel="manifest" href="/manifest.json" />
```

### 🎨 圖片製作建議

#### OG Image 設計要點：
- **尺寸**：1200x630 像素（比例約 1.91:1）
- **內容**：包含網站名稱、主要視覺元素、簡短標語
- **文字**：確保文字清晰可讀，避免過小
- **品牌**：使用品牌色彩和字體
- **檔案大小**：建議 < 1MB，以加快載入速度

#### Favicon 設計要點：
- **尺寸**：建議使用 32x32 或更大的尺寸製作，然後縮放
- **簡潔**：在小尺寸下仍能清楚辨識
- **對比**：確保在不同背景下都清晰可見

### 🔍 SEO 最佳實踐

1. **網站描述**：保持在 150-160 字元之間
2. **關鍵字**：選擇 5-10 個相關關鍵字
3. **圖片 Alt 文字**：為所有圖片添加描述性 alt 屬性
4. **結構化資料**：考慮添加 JSON-LD 結構化資料
5. **Sitemap**：部署後建立 sitemap.xml
6. **robots.txt**：設定適當的 robots.txt

## 📖 組件使用說明

### Footer 組件

```tsx
import { Footer } from '@/components/Footer';

<Footer
  author="Your Name"
  authorLink="https://example.com"
  year={2025}
  showHeart={true} // 可選，預設為 true
/>
```

#### Props

- `author` (string, 必填) - 作者名稱
- `authorLink` (string, 必填) - 作者連結
- `year` (number, 必填) - 年份
- `showHeart` (boolean, 可選) - 是否顯示愛心圖示，預設為 `true`

### FloatingMascot 組件

```tsx
import { FloatingMascot } from '@/components/FloatingMascot';
import mascotImage from '@/assets/mascot.png';

<FloatingMascot
  image={mascotImage}
  link="https://example.com"
  hoverText="聯繫我"
  position="bottom-right" // 可選：'bottom-right' | 'bottom-left'，預設 'bottom-right'
  size="medium" // 可選：'small' | 'medium' | 'large'，預設 'medium'
/>
```

#### Props

- `image` (string, 必填) - 圖片路徑
- `link` (string, 必填) - 點擊後開啟的連結
- `hoverText` (string, 必填) - 懸停時顯示的文字
- `position` ('bottom-right' | 'bottom-left', 可選) - 位置，預設為 `'bottom-right'`
- `size` ('small' | 'medium' | 'large', 可選) - 大小，預設為 `'medium'`

### PageLayout 組件

```tsx
import { PageLayout } from '@/components/PageLayout';
import mascotImage from '@/assets/mascot.png';

<PageLayout
  footerProps={{
    author: 'Your Name',
    authorLink: 'https://example.com',
    year: 2025,
    showHeart: true,
  }}
  mascotProps={{
    image: mascotImage,
    link: 'https://example.com',
    hoverText: '聯繫我',
    position: 'bottom-right',
    size: 'medium',
  }}
>
  {/* 你的頁面內容 */}
</PageLayout>
```

#### Props

- `children` (ReactNode, 必填) - 頁面內容
- `footerProps` (FooterProps, 必填) - Footer 組件的 props
- `mascotProps` (FloatingMascotProps, 必填) - FloatingMascot 組件的 props
- `className` (string, 可選) - 額外的 CSS 類別

## 🎨 設計系統

### 顏色系統

設計系統使用 CSS 變數定義顏色，支援亮色和深色模式：

- `--primary` - 主色
- `--secondary` - 次要色
- `--background` - 背景色
- `--foreground` - 前景色
- `--muted` - 靜音色
- `--accent` - 強調色
- `--destructive` - 破壞性操作色

### 動畫效果

- `animate-float` - 浮動動畫
- `animate-wave` - 搖擺動畫
- `animate-slide-up` - 向上滑入動畫

### 工具類別

- `glass-card` - 玻璃卡片效果
- `gradient-text` - 漸層文字
- `gradient-bg-primary` - 主色漸層背景
- `gradient-bg-secondary` - 次要色漸層背景
- `upload-zone` - 上傳區域樣式

## 🔧 自訂指南

### 修改顏色

編輯 `src/styles/design-system.css` 中的 CSS 變數：

```css
:root {
  --primary: 220 80% 50%; /* 修改主色 */
  --secondary: 175 70% 45%; /* 修改次要色 */
  /* ... */
}
```

### 修改字體

編輯 `tailwind.config.ts` 中的 `fontFamily`：

```typescript
fontFamily: {
  sans: ['Your Font', 'system-ui', '-apple-system', 'sans-serif'],
}
```

### 新增動畫

在 `src/styles/design-system.css` 中新增 `@keyframes` 定義，然後在 Tailwind 設定中新增對應的動畫類別。
