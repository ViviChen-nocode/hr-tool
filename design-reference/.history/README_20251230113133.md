# 設計系統模板 (Design System Template)

> 📖 **這是模板使用說明**：此檔案說明如何使用此模板開發新專案。  
> 📝 **新專案 README 範本**：請參考 [`README_TEMPLATE.md`](./README_TEMPLATE.md)，該檔案包含新專案公開到 GitHub 時的 README 標準格式。

這是一個完整的設計系統模板專案，包含可重用的組件、樣式系統和設定檔，方便您在新專案中快速使用。

## 🎯 模板用途

此模板提供：
- 標準化的設計系統和組件
- 完整的開發流程指引
- 新專案 README 範本（參考 `README_TEMPLATE.md`）
- Cloudflare Pages 部署設定說明

當您使用此模板開發新專案時，AI IDE（如 Cursor）可以參考此專案的結構和設定，協助您快速建立新專案。

## 🚀 新專案開發流程

### 📋 開發前檢查清單

在開始開發前，請確認以下必要元素都已準備：

- [ ] **專案名稱已確認**（資料夾名稱將作為 GitHub 專案名稱）
- [ ] **og-image.png (1200x630)** 已準備（README 主圖）
- [ ] **favicon 系列**已準備（favicon.ico, favicon-16x16.png, favicon-32x32.png）
- [ ] **PWA 圖示**已準備（icon-apple-180x180.png, icon-android-192x192.png, icon-pwa-512x512.png）
- [ ] **網站名稱已確定**（格式：XXXX｜大師姐的工具包）
- [ ] **網站描述**已準備（150-160 字元）
- [ ] **GitHub 專案已建立**，名稱與資料夾名稱一致
- [ ] **所有 GitHub 連結已更新**（README.md 共 3 處）

### 階段一：專案初始化

1. **複製模板資料夾**
   ```bash
   # 直接複製整個資料夾到新位置
   cp -r 00-template-design /path/to/your-new-project
   ```

2. **確認專案資訊**
   - **專案名稱**：使用資料夾名稱（例如：`pdf-tool`、`fb-format`）
   - **GitHub 專案 URL**：`https://github.com/ViviChen-nocode/[專案名稱]`
   - **部署網址**：`https://[專案名稱].vivichen.ai/`
   - 範例：
     - 專案名稱：`pdf-tool` → GitHub: `https://github.com/ViviChen-nocode/pdf-tool` → 網址: `https://pdf-tool.vivichen.ai/`
     - 專案名稱：`fb-format` → GitHub: `https://github.com/ViviChen-nocode/fb-format` → 網址: `https://fb-format.vivichen.ai/`

3. **重新命名專案**
   - 修改 `package.json` 中的 `name` 欄位為你的專案名稱
   - 確認資料夾名稱與 GitHub 專案名稱一致

4. **安裝依賴**
   ```bash
   cd your-new-project
   npm install
   ```

### 階段二：必要元素準備

1. **圖片資源準備**
   - **og-image.png** (1200x630) - 用於 README 主圖和社交分享
   - **favicon 系列** - 網站圖示
   - **PWA 圖示** - 應用程式圖示

2. **網站資訊確認**
   - **網站名稱**：使用「XXXX｜大師姐的工具包」格式
     - 範例：`圖片編輯器｜大師姐的工具包`、`FB轉換神器｜大師姐的工具包`
   - **網站描述**：150-160 字元的描述文字
   - **GitHub 專案名稱**：確認與資料夾名稱一致

### 階段三：修改模板內容

1. **README.md 修改**
   - ⚠️ **重要**：請參考 `README_TEMPLATE.md` 作為新專案 README 的範本
   - 複製 `README_TEMPLATE.md` 的內容到新專案的 `README.md`
   - 替換所有佔位符：
     - `[專案名稱]` → 實際專案名稱（資料夾名稱）
     - `[GitHub連結]` → `https://github.com/ViviChen-nocode/[專案名稱]`
     - 更新網站連結為 `https://[專案名稱].vivichen.ai/`
   - **中間部分**（專案介紹、技術棧、開發說明等）：
     - 依專案需求自由撰寫，不需要標準化格式
     - 可參考 `README_TEMPLATE.md` 中的章節結構

2. **網站設定檔修改**
   - **`public/index.html`**：
     - 更新網站標題為「XXXX｜大師姐的工具包」格式
     - 更新 meta tags（description, og:title, og:url 等）
     - 更新網站 URL 為 `https://[專案名稱].vivichen.ai/`
   - **`public/manifest.json`**：
     - 更新網站名稱為「XXXX｜大師姐的工具包」格式
   - **`package.json`**（可選但建議）：
     - 加入 repository、homepage、bugs 欄位
   - **`src/pages/Example.tsx`**：
     - 修改個人資訊（作者、連結等）

### 階段四：開發與測試

1. **本地開發**
   ```bash
   npm run dev
   ```

2. **功能測試**
   - 測試所有功能是否正常運作
   - 確認響應式設計在不同裝置上正常顯示
   - 檢查所有連結是否正確

### 階段五：部署到 Cloudflare Pages

1. **GitHub 設定**
   - 在 GitHub 建立新專案（如果尚未建立）
   - 確認專案名稱與資料夾名稱一致
   - 將程式碼推送到 GitHub

2. **Cloudflare Pages 設定**
   - 前往 [Cloudflare Dashboard](https://dash.cloudflare.com/)
   - 選擇 **Pages** → **Create a project**
   - 連接 GitHub 專案
   - **建置設定**：
     - **Framework preset**: `無`（或 None）
     - **Build command**: `npm run build`
     - **Build output directory**: `dist`
   - **環境變數**（如需要）：
     - 在 Settings → Environment variables 中設定
     - 例如：API keys、追蹤 ID 等

3. **網域設定**
   - 在 Cloudflare Pages 專案設定中，前往 **Custom domains**
   - 新增自訂網域：`[專案名稱].vivichen.ai`
   - Cloudflare 會自動設定 DNS（如果網域已在 Cloudflare 管理）
   - 等待 DNS 傳播完成（通常幾分鐘內）

4. **部署確認**
   - 確認網站可以正常訪問
   - 檢查所有功能在生產環境中正常運作
   - 確認 og-image 和 favicon 正常顯示

- ✅ `favicon-32x32.png` - 32x32 PNG 格式

- ✅ `icon-apple-180x180.png` - Apple Touch Icon（180x180）
- ✅ `icon-android-192x192.png` - Android 圖示（192x192）

### 📊 Google Analytics 設定（編輯 `public/index.html`）

在 `<head>` 區塊的**最上方**（建議放在 `<meta charset>` 之後）加入 Google Analytics 代碼：

```html
<head>
  <meta charset="UTF-8" />
  
  <!-- Google Analytics (gtag.js) -->
  <!-- 位置：放在 <head> 區塊最上方，確保追蹤準確 -->
  <!-- 追蹤 ID：將 G-BERZ25MNER 替換為你的 GA4 追蹤 ID -->
  <script async src="https://www.googletagmanager.com/gtag/js?id=G-BERZ25MNER"></script>
  <script>
    window.dataLayer = window.dataLayer || [];
    function gtag(){dataLayer.push(arguments);}
    gtag('js', new Date());
    gtag('config', 'G-BERZ25MNER');
  </script>
  
  <!-- 其他 meta tags... -->
</head>
```

#### 設定步驟：

1. **取得 Google Analytics 追蹤 ID**
   - 前往 [Google Analytics](https://analytics.google.com/)
   - 建立新的 GA4 屬性（如果還沒有）
   - 複製你的追蹤 ID（格式：`G-XXXXXXXXXX`）

2. **替換追蹤 ID**
   - 將範例中的 `G-BERZ25MNER` 替換為你的實際追蹤 ID
   - 需要替換兩處：`gtag/js?id=` 和 `gtag('config', ...)`

3. **埋設位置**
   - ✅ **必須放在 `<head>` 區塊最上方**
   - ✅ 建議放在 `<meta charset>` 之後
   - ✅ 使用 `async` 屬性非同步載入，不影響頁面載入速度

4. **驗證設定**
   - 部署後使用 [Google Tag Assistant](https://tagassistant.google.com/) 驗證
   - 或在 GA4 即時報表中查看是否有資料流入

#### 注意事項：

- ⚠️ 開發環境（localhost）預設不會追蹤，這是正常行為
- ⚠️ 確保在生產環境部署後才開始收集資料
- ⚠️ 如果不需要 GA，可以完全移除這段代碼

### 🎨 圖片製作建議

#### OG Image 設計要點：
- **尺寸**：1200x630 像素（比例約 1.91:1）
- **內容**：包含網站名稱、主要視覺元素、簡短標語
- **文字**：確保文字清晰可讀，避免過小
- **品牌**：使用品牌色彩和字體
- **檔案大小**：建議 < 1MB，以加快載入速度

#### Favicon 設計要點：
- **尺寸**：建議使用 32x32 或更大的尺寸製作，然後縮放
- **簡潔**：在小尺寸下仍能清楚辨識
- **對比**：確保在不同背景下都清晰可見

### 🔍 SEO 最佳實踐

1. **網站描述**：保持在 150-160 字元之間
2. **關鍵字**：選擇 5-10 個相關關鍵字
3. **圖片 Alt 文字**：為所有圖片添加描述性 alt 屬性
4. **結構化資料**：考慮添加 JSON-LD 結構化資料
5. **Sitemap**：部署後建立 sitemap.xml
6. **robots.txt**：設定適當的 robots.txt

## 📖 組件使用說明

### Footer 組件

```tsx
import { Footer } from '@/components/Footer';

<Footer
  author="Your Name"
  authorLink="https://example.com"
  year={2025}
  showHeart={true} // 可選，預設為 true
/>
```

#### Props

- `author` (string, 必填) - 作者名稱
- `authorLink` (string, 必填) - 作者連結
- `year` (number, 必填) - 年份
- `showHeart` (boolean, 可選) - 是否顯示愛心圖示，預設為 `true`

### FloatingMascot 組件

```tsx
import { FloatingMascot } from '@/components/FloatingMascot';
import mascotImage from '@/assets/mascot.png';

<FloatingMascot
  image={mascotImage}
  link="https://example.com"
  hoverText="聯繫我"
  position="bottom-right" // 可選：'bottom-right' | 'bottom-left'，預設 'bottom-right'
  size="medium" // 可選：'small' | 'medium' | 'large'，預設 'medium'
/>
```

#### Props

- `image` (string, 必填) - 圖片路徑
- `link` (string, 必填) - 點擊後開啟的連結
- `hoverText` (string, 必填) - 懸停時顯示的文字
- `position` ('bottom-right' | 'bottom-left', 可選) - 位置，預設為 `'bottom-right'`
- `size` ('small' | 'medium' | 'large', 可選) - 大小，預設為 `'medium'`

### PageLayout 組件

```tsx
import { PageLayout } from '@/components/PageLayout';
import mascotImage from '@/assets/mascot.png';

<PageLayout
  footerProps={{
    author: 'Your Name',
    authorLink: 'https://example.com',
    year: 2025,
    showHeart: true,
  }}
  mascotProps={{
    image: mascotImage,
    link: 'https://example.com',
    hoverText: '聯繫我',
    position: 'bottom-right',
    size: 'medium',
  }}
>
  {/* 你的頁面內容 */}
</PageLayout>
```

#### Props

- `children` (ReactNode, 必填) - 頁面內容
- `footerProps` (FooterProps, 必填) - Footer 組件的 props
- `mascotProps` (FloatingMascotProps, 必填) - FloatingMascot 組件的 props
- `className` (string, 可選) - 額外的 CSS 類別

## 🔧 自訂指南

### 修改顏色

編輯 `src/styles/design-system.css` 中的 CSS 變數：

```css
:root {
  --primary: 220 80% 50%; /* 修改主色 */

  /* ... */
}
```

### 修改字體

編輯 `tailwind.config.ts` 中的 `fontFamily`：

```typescript
fontFamily: {
  sans: ['Your Font', 'system-ui', '-apple-system', 'sans-serif'],
```
