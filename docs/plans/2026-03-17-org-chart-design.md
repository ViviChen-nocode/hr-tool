# 組織圖工具設計文件

## 概述

一個純前端的組織圖工具，讓 HR 或任何人都能快速建立、編輯、匯出組織圖。資料存在瀏覽器 localStorage，不需要後端。

## 技術架構

- **框架**：React + Vite
- **組織圖渲染**：React Flow（自訂節點）
- **佈局引擎**：dagre（自動計算樹狀佈局）
- **匯出**：html-to-image（畫布轉 PNG）
- **資料持久化**：localStorage

## 使用流程

### Step 1：首次輸入（全版面）

首次進入或建立新組織圖時，顯示全版面的輸入介面：
- 選擇「表格模式」或「樹狀模式」輸入資料
- 或匯入現有資料
- 輸入完成後點「產生組織圖」

### Step 2：左右分割編輯模式

產生後進入左右分割畫面：
- 左側面板（可調寬度）：表格/樹狀 tab 切換，繼續編輯資料
- 右側畫布：React Flow 組織圖即時預覽
- 左右雙向同步

## 輸入模式

### 表格模式

欄位包含：姓名、職稱、上級（下拉選單）、部門，以及使用者自訂欄位。
- 「上級」下拉自動列出已輸入的人
- 按 Enter 自動新增下一列
- 可新增/刪除列、新增自訂欄位

### 樹狀模式

以縮排樹狀結構顯示組織階層：
- 可拖曳節點調整階層
- 每個節點有「+子級」「編輯」「刪除」操作
- 展開/收合子樹

### 共用資料結構

```typescript
interface OrgMember {
  id: string
  name: string
  title: string
  parentId: string | null
  department?: string
  [customField: string]: any
}
```

表格和樹狀是同一份資料的不同視圖。

## 右側畫布

### 組織圖卡片

每個節點顯示使用者設定的欄位（姓名、職稱、部門等），支援自訂顯示欄位。

### 圖上直接編輯

- 點擊卡片 → inline 編輯文字
- 拖曳卡片到另一個人底下 → 改變上下級關係（左側同步更新）

### 佈局控制

- **方向切換**：上→下（預設）/ 左→右
- **間距滑桿**：水平和垂直間距調整
- **縮放**：滑鼠滾輪 / +- 按鈕
- **置中**：一鍵 fit to view

## 匯出

點「匯出 PNG」→ 將完整組織圖匯出為高解析度圖片。

## 資料持久化

- 自動存 localStorage
- 支援多份組織圖管理（新增 / 切換 / 刪除）
